# Portafolio Web — Lucas Martínez

Sitio web personal diseñado y desarrollado para presentar mi formación académica, experiencia práctica, habilidades técnicas y proyectos de software y redes.

🔗 **Demo en vivo:** [lukasnez.github.io/mi-portfolio](https://lukasnez.github.io/mi-portfolio/)

## 🚀 Características principales
* **Diseño Bento & Minimalista:** Interfaz moderna con modo oscuro nativo y animaciones fluidas.
* **Navegación por anclas:** Desplazamiento suave (`scroll-smooth`) entre secciones (*Sobre mí*, *Habilidades*, *Experiencia* y *Contacto*).
* **Bilingüe (ES / EN):** Selector de idioma dinámico implementado en JavaScript sin recarga de página.
* **Tarjetas interactivas (Modales):** Vista detallada de estudios, trayectoria laboral y laboratorio de redes.
* **Formulario de contacto funcional:** Integración directa con envío de mensajes a correo electrónico.

## 🛠️ Tecnologías utilizadas
* **HTML5**
* **Tailwind CSS** (vía CDN)
* **JavaScript** (Vanilla JS)
* **Git & GitHub Pages**
